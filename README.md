This is an entry for the second Zhihu Hackathon. To run it, please add node_modules and your DeepSeek API to the project root directory.
The goal of the game is to obtain a pass to the Dome by talking with the Agents.
Of course, you can also just wander around and chat with other players and Agents.
The server port is 3000.
